# Accessibility Basics Reference

Web accessibility means building so that people with disabilities can perceive, operate, and understand your site, including those using a keyboard only, a screen reader, magnification, or other assistive technology. The widely used standard is WCAG, which groups its guidelines under four ideas: content should be perceivable, the interface operable, the content understandable, and the markup compatible with browsers and assistive technology. Most of the wins are basic: enough color contrast, real text, keyboard access, labelled controls, and meaningful structure.

This reference covers those basics in plain language, for someone building a site without an accessibility specialist on hand.
